# 🚀 Быстрый старт: Как собрать iOS версию

## GitHub Actions - это БЕСПЛАТНО и НЕ НУЖНО СКАЧИВАТЬ!

GitHub Actions работает прямо на сайте GitHub, в браузере. Это облачный сервис.

## 📝 Шаг 1: Закоммитьте ваши изменения

Выполните эти команды в терминале (PowerShell):

```bash
# Добавить все файлы
git add .

# Создать коммит
git commit -m "Add iOS platform support"

# Отправить на GitHub
git push
```

## 🌐 Шаг 2: Откройте GitHub в браузере

1. Перейдите на: **https://github.com/AyuGram/AyuGramDesktop**
2. Убедитесь, что ваши изменения появились (обновите страницу)

## ⚙️ Шаг 3: Запустите сборку

1. На странице репозитория нажмите вкладку **"Actions"** (вверху)
2. В левом меню найдите **"Build iOS"**
3. Нажмите синюю кнопку **"Run workflow"** (справа вверху)
4. Выберите ветку **"dev"** (где вы работаете)
5. Нажмите зеленую кнопку **"Run workflow"**

## ⏳ Шаг 4: Дождитесь сборки

- GitHub запустит виртуальную Mac машину
- Вы увидите прогресс в реальном времени
- Сборка займет 10-30 минут

## 📦 Шаг 5: Скачайте результат

Когда сборка завершится (зеленый чекмарк):
1. Кликните на выполненный workflow
2. Прокрутите вниз до раздела **"Artifacts"**
3. Скачайте архив с результатами

## ✅ Готово!

Вы собрали iOS версию без Mac! 🎉

---

## 🔍 Где находится GitHub Actions?

**Нигде не нужно скачивать!** Всё работает на сайте:
- **https://github.com/AyuGram/AyuGramDesktop/actions**

Просто откройте эту ссылку в браузере.

## 💡 Автоматический запуск

После того как вы запушите код, GitHub Actions может запуститься автоматически, если вы изменили файлы в `platform/ios/`.

Вы можете отключить автоматический запуск, если хотите запускать только вручную.

## ❓ Проблемы?

- **Не видите вкладку Actions?** - Убедитесь, что Actions включены в Settings → Actions
- **Workflow не запускается?** - Проверьте, что файл `.github/workflows/build-ios.yml` закоммичен
- **Ошибка сборки?** - Проверьте логи в Actions, там будет информация об ошибке
