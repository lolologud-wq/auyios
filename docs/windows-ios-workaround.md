# Обходные пути для сборки iOS на Windows

## ⚠️ Важно
iOS приложения **невозможно** собрать на Windows напрямую. Нужен macOS с Xcode.

## Варианты решения

### 1. 🚀 GitHub Actions (Самый простой)

**Что нужно:**
- GitHub репозиторий (публичный или приватный)
- Файл `.github/workflows/build-ios.yml` (уже создан)

**Как использовать:**
1. Закоммитьте изменения:
   ```bash
   git add .
   git commit -m "Add iOS platform support"
   git push
   ```

2. Перейдите на GitHub → Actions → "Build iOS"

3. Нажмите "Run workflow" → выберите ветку → Run

4. GitHub автоматически соберет проект на Mac runner

**Преимущества:**
- ✅ Бесплатно для публичных репо
- ✅ Не нужен локальный Mac
- ✅ Автоматическая сборка при коммитах

---

### 2. 💻 Удаленный Mac через SSH

Если у вас есть доступ к Mac:

```bash
# На Windows (PowerShell или Git Bash)
ssh username@mac-ip-address

# После подключения к Mac
cd /path/to/AyuGramDesktop/Telegram
cmake -DCMAKE_SYSTEM_NAME=iOS \
      -DCMAKE_OSX_ARCHITECTURES=arm64 \
      -DCMAKE_OSX_DEPLOYMENT_TARGET=13.0 \
      -B build-ios \
      -S .
cmake --build build-ios --config Release
```

**Преимущества:**
- ✅ Прямой контроль
- ✅ Можно дебажить

**Недостатки:**
- ❌ Нужен доступ к Mac

---

### 3. ☁️ Облачные Mac сервисы

**Варианты:**
- **MacStadium** - $99+/месяц, выделенный Mac
- **AWS EC2 Mac instances** - почасовая оплата
- **MacInCloud** - от $20/месяц, удаленный доступ

**Преимущества:**
- ✅ Не нужен физический Mac
- ✅ Полный контроль

**Недостатки:**
- ❌ Платно
- ❌ Медленнее чем локальный Mac

---

### 4. 🔍 Проверка синтаксиса (без сборки)

На Windows можно проверить код на ошибки:

#### Через clangd (если установлен):
```bash
# clangd автоматически анализирует код в редакторе
# Установка: через LLVM или VS Code extension
```

#### Через статический анализ:
- **Visual Studio** - встроенная проверка C++
- **CLion** - встроенный анализ
- **VS Code** с C++ extension - базовая проверка

**Преимущества:**
- ✅ Работает на Windows
- ✅ Находит синтаксические ошибки

**Недостатки:**
- ❌ Не проверяет iOS-специфичные API
- ❌ Не собирает полноценное приложение

---

### 5. 🐳 Docker (НЕ РЕКОМЕНДУЕТСЯ)

⚠️ **ВНИМАНИЕ:** Docker на Windows не может запустить macOS из-за лицензионных ограничений Apple.

---

## Рекомендация

**Используйте GitHub Actions** - это самый простой и бесплатный способ собрать iOS версию без локального Mac.

## Быстрый старт с GitHub Actions

1. Убедитесь, что файл `.github/workflows/build-ios.yml` существует
2. Закоммитьте и запушьте код
3. GitHub автоматически запустит сборку (или запустите вручную в Actions)

## Что дальше?

После успешной сборки на Mac:
- Получите `.ipa` файл
- Подпишите его сертификатом разработчика
- Установите на iOS устройство или симулятор
