# Как использовать GitHub Actions для сборки iOS

## 📋 Что такое GitHub Actions?

GitHub Actions - это **бесплатная встроенная функция GitHub**, её не нужно скачивать! Это облачный сервис, который работает прямо на сайте GitHub.

## 🚀 Быстрая инструкция

### Шаг 1: Закоммитьте код в GitHub

1. **Если у вас еще нет GitHub репозитория:**
   - Создайте аккаунт на https://github.com (бесплатно)
   - Создайте новый репозиторий (New repository)
   - Выберите Public (публичный) - так будет бесплатно

2. **Подключите локальный репозиторий к GitHub:**

   ```bash
   # Добавьте удаленный репозиторий (замените YOUR_USERNAME и YOUR_REPO на свои)
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   
   # Или если уже есть remote, обновите URL:
   git remote set-url origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   ```

3. **Закоммитьте и отправьте код:**

   ```bash
   # Добавьте все файлы
   git add .
   
   # Создайте коммит
   git commit -m "Add iOS platform support"
   
   # Отправьте на GitHub
   git push -u origin main
   # (или git push -u origin master, если у вас ветка master)
   ```

### Шаг 2: Запустите сборку

1. **Откройте ваш репозиторий на GitHub** в браузере
2. **Перейдите на вкладку "Actions"** (сверху навигация)
3. **Найдите workflow "Build iOS"** в списке слева
4. **Нажмите "Run workflow"** (справа вверху)
5. **Выберите ветку** (обычно `main` или `master`)
6. **Нажмите зеленую кнопку "Run workflow"**

### Шаг 3: Следите за сборкой

- GitHub автоматически запустит Mac виртуальную машину
- Вы увидите прогресс в реальном времени
- Когда сборка завершится, вы можете скачать артефакты

## 💡 Важные моменты

### Бесплатные минуты GitHub Actions:

- **Публичные репозитории**: 2000 минут/месяц бесплатно ✅
- **Приватные репозитории**: 2000 минут/месяц бесплатно (первые 12 месяцев), потом 500 минут/месяц

### Что происходит во время сборки:

1. GitHub запускает виртуальную машину macOS
2. Клонирует ваш код
3. Устанавливает Xcode и зависимости
4. Запускает CMake и собирает проект
5. Сохраняет результаты сборки как артефакты

## 🔧 Если что-то пошло не так

### Ошибка: "Workflow not found"
- Убедитесь, что файл `.github/workflows/build-ios.yml` закоммичен
- Проверьте, что он находится в корне репозитория

### Ошибка: "Permission denied"
- Убедитесь, что Actions включены в настройках репозитория:
  - Settings → Actions → General
  - Разрешите "Allow all actions and reusable workflows"

### Сборка не запускается
- Проверьте, что код запушен в правильную ветку (main/master)
- Убедитесь, что файл workflow правильный

## 📦 Где найти результаты сборки?

После завершения сборки:
1. Откройте выполненный workflow (зеленый чекмарк)
2. Прокрутите вниз до "Artifacts"
3. Скачайте архив с результатами сборки

## 🎯 Альтернатива: Автоматический запуск

Workflow настроен так, что автоматически запускается при:
- Push в ветки `main` или `master`
- Изменении файлов в `Telegram/SourceFiles/platform/ios/**`
- Изменении самого workflow файла

Если хотите только ручной запуск, можно изменить workflow (убрать `push` триггер).

## ❓ FAQ

**Q: Нужно ли платить?**
A: Нет, для публичных репозиториев это полностью бесплатно.

**Q: Можно ли использовать приватный репозиторий?**
A: Да, но у вас будет меньше бесплатных минут (500/месяц после первого года).

**Q: Сколько времени занимает сборка?**
A: Обычно 10-30 минут, зависит от сложности проекта.

**Q: Нужен ли мне Mac?**
A: Нет! GitHub предоставляет Mac виртуальные машины в облаке.

**Q: Можно ли собрать для симулятора или только для устройств?**
A: В текущем workflow собирается для устройств (arm64). Можно добавить сборку для симулятора (x86_64).
